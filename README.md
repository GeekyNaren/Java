# Java DSA Practice Repository

Welcome to my Java Data Structures and Algorithms (DSA) practice repository! This collection is designed to help me master fundamental and advanced DSA concepts through hands-on implementation and problem-solving.

## 📂 Repository Structure

The repository is organized by topic, with each folder containing solutions to problems and implementations of core concepts:

- **Array**: Basic array operations, two-pointer techniques, and subarray problems.
- **Hashing**: Frequency counting, two-sum variations, and hash map applications.
- **LinkedList**: Implementation of singly/doubly linked lists, reversal, and cycle detection.
- **MasterBinarySearch**: Advanced binary search patterns, including rotated arrays and search on answer space.
- **MockDSA**: Mock interview problems and mixed-topic challenges.
- **Pattern**: Printing patterns and matrix-based problems.
- **Practice**: General practice problems and random algorithms.
- **Searching**: Linear search, binary search basics, and custom search algorithms.
- **SlidingWindow**: Fixed and variable size window techniques.
- **Sortings**: Implementation of various sorting algorithms (Merge, Quick, Heap, etc.).
- **StackAndQueue**: Stack and Queue implementations, monotonic stacks, and sliding window maximum.
